# 多平台接入说明

更新日期：2026-11-10。

本页描述 v1.0.1，相关更新已包含在安装包和便携包中，详见[发行验证](windows-release-1.0.1.md)。原 v1.0.0 不包含多平台更新；此前的本地测试版记录保留作为历史证据。

**猎聘自动化已暂停。** 用户反馈在尚未完成登录时即出现安全验证和账号风险。当前源码在创建工作器、打开浏览器和使用猎聘登录资料目录前拒绝启动；界面显示“猎聘（已暂停）”。旧配置已选中猎聘时可以取消勾选，取消后不可重新勾选；启动前检查会提示原因，不会自动改用其他平台。分析和后续独立流程要求见[猎聘核验记录](liepin-integration-review-20261110.md)。

## 能力范围

| 能力 | BOSS 直聘 | 智联招聘 | 猎聘 |
| --- | --- | --- | --- |
| 平台选择、独立登录目录 | 既有流程 | 已接入 | 已暂停，保留历史标识和旧目录 |
| 城市和关键词检索、详情读取 | 既有流程 | 实验性适配，含新版滚动列表 | 已暂停，旧解析原型仅保留离线检查 |
| 本地筛选、AI 评分、招呼语草稿、结果记录 | 既有流程 | 复用统一流程 | 本轮不运行，历史结果仍可查看 |
| 平台侧区域、行业、学历、经验等筛选 | 既有流程 | 尚未适配 | 尚未适配 |
| 正式投递 | 沟通消息流程 | 仅识别明确的申请控件及已投递回执 | 已暂停，独立流程未完成 |
| 聊天页、选择简历弹窗 | 既有沟通流程 | 尚未适配 | 尚未适配 |
| 真实账号完整投递验证 | 本次未执行 | 未执行 | 未执行 |

智联属于实验功能，页面解析和投递控件有待真实账号下进一步验证。智联的招呼语保存在结果中作为草稿，当前不会进入平台聊天窗口发送。猎聘的搜索、登录身份确认、验证停止和投递必须分别核验，不能由通用浏览器流程推定可用。

## 使用方法

从源码启动 `desktop_panel.py`，或运行 v1.0.1，在“求职设置 → 简历与搜索 → 招聘平台”勾选 BOSS 或智联。默认只选 BOSS 直聘。旧配置包含猎聘时，先取消勾选并保存。先保留试运行，核对城市、列表、岗位详情及评分结果。

可用平台顺序运行，各平台首次使用需要分别登录。若配置中包含已暂停平台，整个任务在启动前报错。通过配置检查后，单个平台遇到限制会保存结果并停止，调度器可以继续处理其他已选平台。主动停止整个任务时不会启动后续平台。

本轮 AI 评估数量按剩余平台分配。例如目标 10 个、选择 BOSS 和智联，第一平台最多分到 5 个，后续按实际消耗重新分配剩余数量；前一平台不足时，后续平台可以使用未完成的名额。目标比平台数量小时，后面的平台可能没有名额。每日投递上限共用同一本地记录。

`JOB_PLATFORMS` 支持中文名称和 ID，例如：

```dotenv
JOB_PLATFORMS=BOSS 直聘,智联招聘
CITY_CODE=101280600
DRY_RUN=true
ZHILIAN_CITY_CODE=
```

`CITY_CODE` 沿用工作城市下拉框中的代码，各平台搜索使用自己的城市代码。BOSS 平台筛选条件只对 BOSS 生效；本地区域、作息、简历和职业范围等条件继续使用公共流程。只选智联时，BOSS 专用控件会禁用。`liepin` 和“猎聘”仍能解析，以保留旧配置及历史结果兼容，但不能启动。

## 城市代码

| 工作城市 | 智联 | 猎聘旧原型代码（当前不运行） |
| --- | --- | --- |
| 北京 | `530` | `010` |
| 上海 | `538` | `020` |
| 广州 | 需手工设置 | `050020` |
| 深圳 | `489` | `050090` |

智联其他城市在“高级设置 → 采集细节”填写城市代码，取自官方搜索页地址，例如 `/sou/jl489/` 中的 `489`。代码独立保存，不从 BOSS 代码推算。填写代码后仍需检查官方页面展示的城市是否正确。猎聘旧代码仅作记录，其高级设置控件已禁用；参考资料中的 `city/currentPage` 与旧原型的 `dqs/curPage` 不同，尚未在线核验。

启动前会检查所有所选平台的城市配置；未收录且未填写的城市会明确报错。检索时也检查页面或岗位中的城市信息，明显不匹配会停止。

## 投递状态与历史

- `delivered`：当前岗位申请区出现明确的已投递或申请成功状态。
- `manual_required`：显示“需人工投递”；未识别到适配的申请按钮，不点击聊天入口，不增加每日投递计数。
- `delivery_unconfirmed`：显示“投递待核对”；已触发申请，但未确认成功回执。保留已取得的评分和草稿，计入当日尝试次数并停止该平台，同一岗位后续不会自动重试。
- `already_contacted`：复用已处理状态；新平台表示当前岗位已投递，跳过重复评分或申请。

待核对和需人工投递的记录均进入“待复核”筛选，可从详情链接打开官方岗位页检查。未确认记录没有自动重置入口，应先核对官方记录；确认未投递且需要重试时，备份结果 CSV 后人工修正对应记录。

新平台标识形如 `zhilian:ABC123`、`liepin:job:123`，猎聘的 `/a/123.shtml` 和 `/job/123.shtml` 也分别保留身份。BOSS 原有岗位 ID 不变。不同平台的原生 ID 相同不会相互去重；同一公司跨平台发布的岗位目前不做语义合并。

结果 CSV 新增“平台”和“平台岗位ID”字段。首次写入旧格式文件时，先生成原字节备份，再迁移已有行；缺失平台的历史记录归为 BOSS 直聘。

浏览器登录资料分别保存在：

```text
%USERPROFILE%\.boss-zhipin-scraper\chrome-profile
%USERPROFILE%\.autodeliver-zhilian\chrome-profile
%USERPROFILE%\.autodeliver-liepin\chrome-profile
```

猎聘目录为旧原型路径。暂停补丁不会创建、打开、复制或清理该目录，也不会修改账号风险状态。

## 实现与验证

`platform_worker.py` 负责平台顺序和数量分配；`job_platforms.py` 统一平台、城市、官方链接及岗位身份，并提供启动前的暂停检查；`platform_browser.py` 和 `platform_job_parser.py` 保留页面原型；`platform_deliverer.py` 复用 `AutoDeliverer` 的本地筛选、评分和结果处理。调度器、直接工作器入口和浏览器构造器均拒绝猎聘启动。登录、搜索和申请动作的独立适配仍是猎聘恢复的前提。

智联新版卡片没有可用链接时，只读取与可见标题、公司、薪资、城市相符的 Vue 绑定数据，并验证岗位 ID 与官方详情链接一致。滚动加载根据页面明确的 `hasMore` 状态继续，搜索页与详情页分别保留标签页；页面结构或加载状态无法识别时停止。

验证命令：

```powershell
python -X utf8 -B -m pytest tests -q
python -X utf8 -B scripts/verify_multiplatform.py
git diff --check
```

单元测试覆盖配置传递、城市和链接、解析、平台隔离、历史迁移、未确认投递、顺序调度、总量分配及 Qt 控件。浏览器自检使用 localhost 模拟页面、临时浏览器资料目录和真实 Chromium，检查登录标识、列表、详情、明确回执、智联绑定数据与滚动加载、限制停止，不访问招聘账号、不调用 AI、不发送真实投递。

2026-11-10 初版接入的历史验证结果（猎聘暂停补丁前）：

- 全量测试：459 项测试、190 项子测试通过。
- `scripts/verify_multiplatform.py`：9 项检查通过，包括拒绝将公开姓名或“我的简历”链接当成登录凭据、读取详情后继续加载智联列表。
- Qt 离屏界面检查：在 `1420×900` 和最小窗口 `1180×760` 查看平台选择区、城市代码及模拟结果；平台控件没有重叠或文字截断，平台列在表格最前方。
- `scripts/check_sensitive_data.py`：通过。
- 初版接入验证时没有重新构建 EXE、安装包或便携 ZIP；后续本地打包结果见[构建记录](windows-local-test-20261110-search-results.md)。

公开页面只读检查中，猎聘页面能够读取部分岗位列表和详情，随后出现安全验证；智联返回安全验证页面。此时结束检查，未继续访问受限页面。参考的选择器来自公开页面和 [AgentMesh-JobAgent](https://github.com/jiyangnan/AgentMesh-JobAgent)，浏览器接口以 [DrissionPage](https://github.com/g1879/DrissionPage) 为准。公开页面观察和本地模拟检查不能证明真实账号的投递流程已经可用。

猎聘暂停补丁后的历史验证：全量 462 项测试、190 项子测试通过；localhost Chromium 9 项检查、敏感信息扫描和 `git diff --check` 通过。该阶段未访问招聘平台、账号或用户浏览器资料目录，未执行 AI 调用和真实投递，当时未重新构建发行包。后续本地测试版保持猎聘暂停，构建前全量测试为 513 项测试、231 项子测试通过，详见[构建记录](windows-local-test-20261110-search-results.md)。猎聘独立流程边界见[核验记录](liepin-integration-review-20261110.md)。
