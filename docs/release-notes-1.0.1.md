# AutoDeliver v1.0.1

发布日期：2026-11-10。Windows x64。

## 更新内容

- 支持多个关键词分别搜索、合并去重，展示每词搜索统计，并在连续重复页面时停止继续翻页。
- 投递结果新增岗位链接入口，使用项目配置的 Chrome/Edge 及对应平台登录目录；登录仍有效且保留登录信息时可沿用账号。
- 结果列表支持筛选、勾选、全选本页和批量删除；行内删除列位于最右侧，删除前确认并备份本地记录。
- 新增智联招聘实验性接入，BOSS 与智联分别使用平台流程及登录目录。猎聘自动化因账号风险反馈继续暂停，在启动浏览器前拦截。
- 改进推荐岗位范围、当前城市意向及匹配规则，识别平台限制后停止并保存已完成结果。
- 更新 README、平台说明和搜索建议；应用、EXE 与安装器统一版本号为 1.0.1。

## 下载与升级

发行附件为 `AutoDeliver-Setup-1.0.1-win64.exe`、`AutoDeliver-1.0.1-win64-portable.zip` 和 `SHA256SUMS.txt`。安装版沿用原应用标识；升级前关闭工作台和项目浏览器，并备份 `%APPDATA%\AutoDeliver`。便携版完整解压至新目录后运行，不能单独移动 EXE。

## 使用范围

发布前全量检查通过 513 项测试、231 项子测试；冻结 GUI/worker 离线自检、508 个便携包文件逐项校验、隔离安装及卸载均通过，8 个既有非日志数据文件保持一致。

智联尚未完成真实账号完整登录与投递验证；猎聘未恢复自动化。请先试运行并人工核对岗位和生成内容。发布验证仅使用本地模拟数据、隔离数据目录和本地浏览器页面，没有调用外部 AI 或发送真实投递。

结果删除只影响本地历史，不撤回平台投递，删除后岗位可能再次进入处理。运行任务时请先结束任务再打开结果岗位链接或删除记录。安装包和 EXE 尚未代码签名。
